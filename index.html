Get the daily widget

iPhone — easy 2 MIN

  1. Open this page in Safari.
  2. Tap Share → Add to Home Screen → Add.
  3. Tap the icon each morning — a new quote is waiting.

iPhone — true widget WIDGY

  1. Install the free Widgy app.
  2. Create a widget, add a URL text layer pointing to
    https://forgedreams-ai.github.io/purposeful-widget/today.json
  3. Display the .quote field (and .author underneath). Add the Widgy widget to your home screen.

Android — easy 2 MIN

  1. Open this page in Chrome.
  2. Tap ⋮ → Add to Home screen.
  3. Tap the icon each morning — a new quote is waiting.

Android — true widget KWGT

  1. Install the free KWGT app and add a KWGT widget to your home screen.
  2. Add a text layer with this formula:
    $wg("https://forgedreams-ai.github.io/purposeful-widget/today.json", json, ".quote")$
  3. Add a second text layer for the author:
    $wg("https://forgedreams-ai.github.io/purposeful-widget/today.json", json, ".author")$

The widget updates itself — every quote we post gets added here, and the quote of the day rotates automatically.
